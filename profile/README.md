
# BYU // LABS

**An academic sandbox and course repository hub for computer science at BYU.**

BYU // LABS is a place to explore coursework, experiment with software, and
share projects built along the way. The repositories cover programming
fundamentals, object-oriented design, web development, and computer science
concepts through hands-on projects.

## Explore

- **[Projects and coursework](https://github.com/orgs/BYULabs/repositories)** —
  Browse the organization's public repositories.
- **[BYU // LABS website](https://byulabs.github.io/)** — Explore project
  highlights and the portfolio.
- **[Popular repositories](https://github.com/BYULabs?tab=repositories)** —
  Find some of the community's most-starred work.

## What you'll find

- Web projects built with JavaScript, HTML, and CSS.
- Java projects practicing object-oriented programming and software design.
- Coursework and small experiments exploring core computer science topics.

## Get involved

Explore a repository's README for project details, setup instructions, and
course context. If you have a question or suggestion, open an issue in the
relevant repository.

Coursework is shared for learning and portfolio purposes. Please follow your
course and institution's policies when referencing or reusing academic work.
